# claude-ichiba (市場)

A [Claude Code](https://claude.ai/code) [plugin marketplace](https://code.claude.com/docs/en/plugin-marketplaces) by Gwenneg Lepage.

## Plugins

| Plugin | Description |
|---|---|
| [ai-mentor](https://github.com/gwenneg/ai-mentor) | Describe your engineering problem, get the right AI workflow. Ranked, verified recommendations with ready-to-paste prompts that teach you why each approach works |
| [mintmaker-automerge](https://github.com/gwenneg/mintmaker-automerge) | Renovate automerge for low-risk dependency updates in Konflux-onboarded repositories, one decision at a time, with the branch-protection steps that make it safe |
| [soundings](https://github.com/gwenneg/soundings) | Take soundings before you ship - release confidence scores and risk reports for GitHub/GitLab compare URLs |
| [soundings-app-interface](https://github.com/gwenneg/soundings-app-interface) | Release confidence analysis for Red Hat app-interface merge requests, built on soundings |
| [togi](https://github.com/gwenneg/togi) | Captures AI coding friction and turns recurring doc gaps into context-doc pull requests |

## Install

In Claude Code:

```
/plugin marketplace add gwenneg/claude-ichiba
/plugin install ai-mentor@claude-ichiba
/plugin install mintmaker-automerge@claude-ichiba
/plugin install soundings@claude-ichiba
/plugin install soundings-app-interface@claude-ichiba
/plugin install togi@claude-ichiba
/reload-plugins
```
